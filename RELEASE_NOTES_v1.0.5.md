# Rule34Swift v1.0.5

## Русский

### Возможности

- Поиск через сайт Rule34.xxx (booru-парсер) или DAPI.
- Просмотр изображений и видео в полноэкранном просмотрщике с масштабированием.
- Избранное с импортом и экспортом JSON.
- Подсказки тегов и расширенный синтаксис поисковых запросов.
- Настройка качества обложек и оригиналов, управление кэшем и фильтр AI-постов.
- Обработка ответов CAPTCHA и проверки возраста.
- Интерфейс без рекламы.

### Изменения

- Обновлено описание возрастного содержимого в README.
- Добавлена инструкция первого запуска macOS при предупреждении Gatekeeper.
- Версия приложений обновлена до 1.0.5.

### Загрузки

- iOS: `Rule34Swift.ipa`
- macOS: `Rule34SwiftMac.dmg`

Сборки подписаны ad-hoc и не нотариально заверены. Для macOS может потребоваться разрешить первый запуск в разделе «Конфиденциальность и безопасность».

## English

### Features

- Search Rule34.xxx through its website parser or DAPI.
- View images and videos in a full-screen viewer with zoom.
- Favorites with JSON import and export.
- Tag suggestions and advanced search syntax.
- Separate quality settings for previews and originals, cache management, and AI post filtering.
- CAPTCHA and age-verification response handling.
- Ad-free interface.

### Changes

- Updated the content notice in the README.
- Added macOS first-launch instructions for Gatekeeper warnings.
- Updated the app version to 1.0.5.

### Downloads

- iOS: `Rule34Swift.ipa`
- macOS: `Rule34SwiftMac.dmg`

Builds are ad-hoc signed and not notarized. On macOS, you may need to allow the app to open in Privacy & Security on first launch.
